⚖️ Good Project vs Risky Project

Good Project

  • Small enough to finish
  • One core feature works really well
  • Easy to explain in 30 seconds
  • Built one feature at a time
  • Tested after every change

Risky Project

  • 10 giant features planned
  • Huge GUI before logic works
  • API + database + game engine all at once
  • Hard to explain what it does
  • Never tested until the end
"Finished and clear beats ambitious and broken."

🤖 AI Use Rules

You MAY Use AI To…

  • Brainstorm project ideas
  • Get starter code for one feature
  • Explain error messages
  • Refactor messy code
  • Generate tests or sample data

You May NOT…

  • Submit code you cannot explain
  • Paste giant blocks blindly
  • Skip testing because "AI wrote it"
  • Ask AI to do the entire project
If you cannot explain what the code does, it is not finished.
